# Concept C redesign notes

The `redesign/concept-c` branch applies a shared Modern Hybrid Research Platform layer to all existing HTML pages. It preserves the existing page bodies, canonical tags, JSON-LD, sitemap, redirects/robots files, affiliate disclosures, research content, and browser tools while replacing the fragmented visual shell with:

- a navy/teal global navigation and mobile menu;
- a consistent information architecture for Research, Risk Intelligence, Prop Firms, Tools, Education, Search, and Methodology;
- light editorial reading surfaces with serif article treatment;
- evidence-aware tables, source boxes, badges, and footers;
- responsive layouts for desktop and Android-sized screens.

No production branch, deployment, DNS, or database was changed. The branch is ready for review only.
