## Visual rules

- Obsidian background with layered charcoal surfaces.
- Gold for editorial hierarchy, active states, and evidence emphasis.
- Cyan for verified/source-linked information and secondary accents.
- Inter/system typography, uppercase tracked navigation, and compact eyebrow labels.
- Rounded 18px cards, hairline borders, restrained gradients, and horizontal overflow for dense tables.
- Mobile navigation wraps intentionally and all multi-column grids collapse to one column.
