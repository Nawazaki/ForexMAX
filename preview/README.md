# ForexMax Visual Concepts

Isolated, non-production visual comparison for three redesign directions. The source repository remains unchanged on `main`; this work is on `preview/three-design-concepts`.

## Concepts

- **A — Premium Financial Intelligence Terminal:** dark navy, mono metadata, dense evidence desk, understated borders.
- **B — Editorial Financial Research Journal:** ivory paper, serif display type, publication hierarchy, source-led reading flow.
- **C — Modern Hybrid Research Platform:** navy masthead, light research surfaces, rounded analytical modules, clear tool separation.

## Preview

Open `index.html` and use the concept tabs and page links. The page includes desktop-responsive and mobile-responsive states, the same evidence-aware sample content, a comparison table, an article layout, methodology, and working browser-only position size, risk/reward, and timezone tools.

No production routes, DNS, database, deployment, or canonical metadata were changed. The final redesign must wait until the owner selects A, B, or C.
